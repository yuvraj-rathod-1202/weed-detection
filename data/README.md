# Data

Not version-controlled. Expected layout:

```text
data/
├── raw/<dataset>/
│   ├── images/          *.jpg / *.png
│   ├── labels/          YOLO boxes, same stem as the image: <cls> <cx> <cy> <w> <h> (normalized)
│   └── classes.txt      one class name per line (line index = class id)
└── processed/<dataset>_seg/     generated by scripts/prepare_data.py (do not edit)
    ├── images/{train,val,test}/
    ├── labels/{train,val,test}/  YOLO-seg: <cls> <x1> <y1> <x2> <y2> ... (normalized polygon)
    ├── splits.json               which image is in which split
    ├── data.yaml                 ultralytics dataset file
    ├── sam_fallbacks.txt         boxes where SAM returned no mask (box polygon used)
    └── prepare_info.json         settings + per-split/per-class counts
```

## CottonWeedDet12

12 weed species from US cotton fields (Dang et al., 2023), YOLO box labels. Download it from the
official release (Zenodo / the authors' GitHub) and arrange it as above in
`data/raw/cottonweeddet12/`. The local copy currently has 2,391 images.

## GT masks

The dataset has boxes only. `prepare_data.py` prompts SAM (`sam_model` in the dataset config)
with each GT box and stores the resulting polygon as the GT mask. These are **pseudo-labels**:
check them in `notebooks/01_data_exploration.ipynb` and report this in the paper.
